Kodak Thermal Ribbon Respooler

During a Summer 2025 automation engineering internship at Kodak Alaris, this project turned a manually intensive prototype process into a compact respooling machine for isolating defects in long rolls of thermal transfer ribbon.

Back to all project portfolios

Project Goal

Find defects without scrapping whole rolls

Kodak Alaris needed a way to locate defects inside roughly 1,000-foot ribbon rolls, rewind to the right position, and recover the usable material with less operator time and less waste.

Scope

Concept through deployment

The work covered mechanical design, PLC logic, HMI development, motion control, encoder feedback, electrical integration, pneumatics, vendor coordination, and final machine implementation.

System Architecture

A compact rewinding machine with industrial controls

Motion system

A Schneider Electric Lexium MDrive integrated stepper motor handled spool motion and variable-speed ribbon transport so the machine could rewind to operator-selected locations.

Position tracking

An incremental encoder served as the primary feedback device, letting the machine monitor ribbon travel and stop near the requested defect location.

PLC control

Allen-Bradley PLC tooling in RSLogix 500 and RSLogix 5000 coordinated machine states, motion commands, operator inputs, encoder counts, and pneumatic actions.

Operator interface

An HMI built in Allen-Bradley Connected Components Workbench let operators enter target positions, start rewind actions, and monitor machine status without needing to interact directly with low-level control logic.

Technical Challenges

  • Resolved encoder signal mismatch by converting an NPN output into a PLC-compatible PNP-style input using a relay interface.
  • Built a 4-bit command architecture between the PLC and motor controller, creating 15 defined actions inside a simple command set.
  • Managed small cumulative count errors over long rewinds and still reached approximately plus-or-minus 5 millimeters over 10 meters of travel.
  • Integrated pneumatics, motion, sensing, and controls into a machine small enough to fit the intended manufacturing workflow.

Engineering Contributions

  • Mechanical design of the ribbon handling and spooling hardware
  • PLC state logic and machine sequencing
  • HMI development for operator control and status display
  • Python-based encoder and counting-logic verification
  • Vendor coordination, component selection, testing, and deployment support

Results

Production-focused automation rather than a lab-only prototype

Manual labor reduced

The completed system automated a previously hands-on respooling workflow and cut down the operator effort required to isolate defects.

Material recovery improved

Instead of treating the whole roll as compromised, operators could rewind precisely, separate bad material, and keep more of the usable ribbon.

Positioning validated

The encoder-driven approach gave the team a measurable position-tracking system over long ribbon lengths rather than relying on estimation or manual indexing.

Cost remained practical

The project summary reports an approximate machine cost of $2,500 while still delivering a compact manufacturing solution with controls, feedback, and operator interface built in.

Project Context

  • Internship: Automation Engineer Intern, Kodak Alaris, Summer 2025
  • Team structure: 6 engineers and 3 external suppliers or vendors
  • Controls stack: Allen-Bradley PLCs, RSLogix 500/5000, CCW HMI tools
  • Key hardware: stepper motor, incremental encoder, vacuum table, pneumatics

Takeaways

  • This project combines manufacturing pragmatism with controls engineering rather than stopping at a concept demo.
  • The strongest engineering move was reducing the operator problem to measurable machine states, positions, and commands.
  • It also shows a valuable pattern from industry work: a modest machine can create outsized value if it removes a recurring pain point.
