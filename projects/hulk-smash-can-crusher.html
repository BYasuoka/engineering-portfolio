Hulk Smash Can Crusher

This team project combined a crank-slider crushing mechanism with Arduino-based logic, audio, sensing, and a user interface to create an automated aluminum can crusher that is part machine design exercise and part interactive product experience.

Back to all project portfolios

Team

Group 2, Colorado State University

Report authors listed: Isabella Kaze, Brenton Yasuoka, and Nathan Madachy. The final report is dated May 9, 2025.

Core Idea

Automate the crushing cycle safely

The machine detects a can, lets the user select the drink category, announces the impending crush with themed audio, crushes the can automatically, and records usage data on an LCD display.

Mechanical System

A crank-slider mechanism built around torque and repeatability

Drive hardware

The report specifies a 24-volt, 150-watt, 100-RPM brushed DC motor driving a gear train with a 6:1 ratio to generate enough torque for crushing.

Crushing stroke

An 8-inch crank-slider stroke allows the system to accommodate both standard cans and taller can formats while keeping the motion path simple.

Cycle time

The team reports that the selected ratio and motor combination could crush a can in under five seconds, which is a nice balance between visible motion and practical speed.

Safety features

The frame and crushing channel were designed so cans stay contained during crushing, while an emergency stop and reset logic protect the user during abnormal operation.

Controls and Sensing

  • Arduino Mega selected to handle the larger I/O count required by switches, sensors, LCD, motor controller, and audio module.
  • A two-plate conductivity sensor detects whether an aluminum can is actually in place before the machine runs.
  • A limit switch establishes the home position and confirms completed crushing cycles.
  • An interrupt-driven emergency stop immediately halts motion regardless of what the main loop is doing.

User Experience Layer

  • 16x2 LCD gives live instructions, countdown cues, crush totals, and stored can-category counts.
  • Manual buttons let the user select categories such as energy drink, coffee or tea, soda, beer, and other.
  • A DFPlayer Mini and speaker play the “Hulk Smash!” audio cue before the crushing cycle starts.
  • The system turns a simple recycling task into a guided and slightly playful interaction.

Why The Project Works

It is a complete system, not just a moving mechanism

Automatic sensing

The crusher does not just run on command; it confirms the presence of a conductive can, which helps block accidental misuse with non-aluminum objects.

Closed user loop

Audio, display prompts, category selection, cycle counting, and reset behavior all make the machine understandable to the person using it.

Affordability mindset

The report highlights deliberate component reuse, custom-built sensing hardware, and data-backed motor selection to keep the design practical rather than overbuilt.

Mechanical-electrical integration

This is the strongest engineering lesson in the report: the device only succeeds because mechanism, controls, sensing, and safety were all developed together.

Lessons Learned

  • Sensor reliability matters as much as actuator power in an automated machine.
  • Re-homing after interruptions is essential once moving hardware is involved.
  • Small UX touches like prompts and audio can make a student build feel much more complete.
  • Testing compression force and containment early reduces risk later in the project.
